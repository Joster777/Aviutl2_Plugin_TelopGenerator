# テロップ自動生成 (TelopGenerator) - AviUtl ExEdit2 汎用プラグイン

動画の音声を **文字起こし** して、字幕を一覧で確認・修正してから、**テロップとして自動で配置** するプラグインです。
音声認識(whisper.cpp)をプラグインに内蔵しているので、外部のソフトやサービスは必要ありません。

修正した内容は **辞書として学習** され、次回以降の認識結果に自動で反映されます。

## 特長

- タイムライン上の音声を **そのまま文字起こし**(範囲選択があれば、その範囲だけ)
- 認識した字幕を **一覧で表示**。文字・開始時間・終了時間を、その場で修正できる
- 字幕の **分割・結合・削除** に対応
- 修正した内容を **辞書に学習** し、次回から自動で直る
- **BGM や効果音を除いて、声だけを抽出** してから文字起こしできる(誤認識を減らせます)
- 無音検出(VAD)で、**話していない部分の誤認識を防ぐ**
- テロップの見た目は、**エイリアス**(好きなテキストオブジェクトの設定)で選べる。配置前に値を編集することも可能
- GPU に対応(GPU 版としてビルドされている場合)

## 動作環境

- AviUtl ExEdit2(RequiredVersion 2003300 以上)
- Windows 10 / 11

## 導入方法

**モデルファイルは zip に同梱されています。** 解凍してコピーするだけで使えます。

1. [Releases](../../releases) ページから、最新版の zip をダウンロードします。
2. zip を解凍し、中身をプラグインフォルダにコピーします。
3. AviUtl ExEdit2 を起動(再起動)します。

### 同梱しているファイル

```
TelopGenerator_vx.x.zip
├─ Plugin/
│   ├─ models/
│   │   ├─ ggml-large-v3-q5_0.bin       文字起こし
│   │   ├─ ggml-silero-v5.1.2.bin       無音検出
│   │   └─ UVR-MDX-NET-Voc_FT.onnx      声の抽出
│   └─ TelopGenerator.aux2
├─ LICENSE.txt                       本プラグインのライセンス
└─ THIRD_PARTY_NOTICES.txt           同梱モデル・ライブラリのライセンス表示
```

`models` フォルダは、`.aux2` と同じ場所に置きます。

### モデルについて

| 用途 | ファイル | 配布元 |
|---|---|---|
| 文字起こし(必須) | `ggml-large-v3-q5_0.bin` | [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-q5_0.bin) |
| 無音検出(推奨) | `ggml-silero-v5.1.2.bin` | [ggml-org/whisper-vad](https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin) |
| 声の抽出(任意) | `UVR-MDX-NET-Voc_FT.onnx` | [TRvlvr/model_repo](https://github.com/TRvlvr/model_repo/releases/download/all_public_uvr_models/UVR-MDX-NET-Voc_FT.onnx) |

- 文字起こしのモデルは、`models` フォルダ内の `.bin` のうち、**最も大きいファイル** が使われます。別の whisper のモデルに差し替えることもできます。
- 無音検出のモデルは、ファイル名に `silero` または `vad` を含む `.bin` として認識されます。無いと、話していない部分の誤認識が出やすくなります。
- 声の抽出のモデル(`.onnx`)は、「声を抽出」を使うときだけ必要です。
- 文字起こしのモデルが無いと、「モデルがありません」と表示されます。その場合は、上の配布元から入手して `models` フォルダに置いてください。

## 使い方

### 基本の流れ

1. メニューから **「テロップ自動生成」** ウィンドウを開きます。
2. タイムラインで、**文字起こししたい音声のあるレイヤーを選択** します。
   範囲選択をしていれば、その範囲だけが対象になります。
3. **「文字起こし」** を押します。
4. 認識された字幕が一覧(#・開始・終了・テキスト)に表示されます。
5. 必要に応じて、字幕を修正します。
6. **テロップを置きたいレイヤーを選択** して、**「テロップ配置」** を押します。

### 字幕の修正

一覧の字幕を選んで、下の欄で修正します。

| ボタン | 内容 |
|---|---|
| 反映 | 修正した文字や時間を、一覧に反映する |
| 分割 | カーソルの位置で、字幕を2つに分ける |
| 結合 | 字幕を1つにまとめる |
| 削除 | 字幕を削除する |

時間は **「1:23.4」** または **「83.4」** の形式で入力します。

### 修正を学習する

配置したテロップの文字を、タイムライン上で直したあとに **「修正を学習」** を押すと、直した内容が辞書に登録されます。
登録前に、確認のメッセージが表示されます。次回以降の文字起こしで、同じ間違いが自動で直ります。

### 声を抽出する

**「声を抽出」** にチェックを入れると、BGM や効果音を除いて声だけを取り出してから、文字起こしします。
BGM が大きい動画で、誤認識が多いときに有効です。`.onnx` のモデルが必要です。

### エイリアスでテロップの見た目を選ぶ

- **「エイリアスを選択」**: テロップに使うエイリアスを選びます(テキストのオブジェクトを含むものだけが表示されます)。
  選ばない場合は「標準のテロップ」が使われます。
- **「エイリアスを編集」**: 選んだエイリアスの値(色、サイズなど)を、配置前に変更します。
  **元のエイリアスのファイルは変更されません。**

エイリアスは、AviUtl2 のアプリケーションデータフォルダ内の `Alias` フォルダに保存したものが対象です。

### データフォルダを開く

**「データフォルダを開く」** で、辞書や設定ファイルが入ったフォルダを開けます。

## 設定ファイル(settings.txt)

初回の起動時に、アプリケーションデータフォルダの `TelopGenerator` フォルダに `settings.txt` が作られます。
`項目名=値` の形式で、**変更後は次の文字起こしから反映されます。**

| 項目 | 内容 | 初期値 |
|---|---|---|
| vad | 無音検出を使うか(1=使う / 0=使わない) | 1 |
| vad_threshold | 話し声と判定する基準。小さいほど拾いやすい(0.1〜0.5) | 0.2 |
| vad_min_silence_ms | この長さ以上の無音で区切る | 200 |
| vad_max_speech_s | 1区間の最大秒数 | 10 |
| vad_pad_ms | 話し声の前後に足す余白 | 300 |
| normalize | 音量を自動で揃えるか | 1 |
| target_rms | 揃える音量の目安(0.05〜0.2) | 0.1 |
| highpass_hz | これより低い音を弱める。0 で無効 | 100 |
| logprob_thold | 小さいほど、自信のない認識結果も採用する | -2.0 |
| no_speech_thold | 大きいほど、「話していない」と判断されにくい(0〜1) | 0.9 |
| max_chars | 1つの字幕の最大文字数 | 24 |
| split_gap_s | 話し声の間にこの秒数以上の間があれば、字幕を分ける | 0.3 |
| split_by_speech | 話し声の区間に合わせて、字幕の位置を詰める | 1 |
| gpu_device | 文字起こしで使う GPU の番号 | 0 |
| separate | 「声を抽出」の初期値(1=オン / 0=オフ) | 1 |
| separate_gpu | 声の抽出で GPU(DirectML)を使うか(0=CPU のみ) | 1 |
| ort_device | 声の抽出で使う GPU の番号 | 0 |
| ignore_no_speech | ignore.txt と一致した字幕を、無音確率がこの値より高いときだけ除外する | 0.3 |

RTX 搭載の PC で、Intel の内蔵 GPU が選ばれてしまう場合は、`gpu_device` や `ort_device` を `1` などに変えてください。

### 除外リスト(ignore.txt)

無音や環境音のときに、音声認識が出してしまいがちな定型文(「ご視聴ありがとうございました」など)を、字幕から除外するリストです。
1行に1フレーズ書きます。句読点を除いて **完全に一致した字幕だけ** が除外されます。実際に話す言葉は、リストから消してください。

## 注意事項

- 文字起こしの結果には、**誤認識が含まれることがあります**。配置する前に、必ず内容を確認してください。
- 出力(エンコード)中は、文字起こしやテロップの配置は実行できません。
- テロップを置く位置に、**すでに別のオブジェクトがある場合は、その字幕は配置されません**。配置先のレイヤーを空けてください。
- 文字起こしには、**時間がかかる** ことがあります(モデルの大きさや、動画の長さによります)。
- 処理中に内部エラーが起きたときは、`TelopGenerator` フォルダの `crash.txt` を確認してください。
- 実行前に、プロジェクトの保存(バックアップ)をおすすめします。
- 本プラグインを使用したことによる、いかなる損害についても責任を負いません。
